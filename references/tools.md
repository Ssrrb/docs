# Tools and references

This file is the internal wiki of the team. The file lists the tools and the references that the team uses. Each entry states which tool answers which need.

This file creates no rule. This file does not replace `AGENTS.md`. This file does not replace the knowledge folders of the project.

## Choose a tool

| If you want to | Use |
|---|---|
| Verify a rule that a machine can verify | `scripts/check.sh` |
| Design the interface of a function | [Figma](#figma) |
| Learn application architecture and data systems | [*Designing Data-Intensive Applications*](#designing-data-intensive-applications) |
| Add error telemetry | [Sentry](#sentry) — planned, not integrated |
| Review production errors | [Sentry](#sentry) — planned, not integrated |
| Write or publish documentation | [docs.page](#docspage) |
| Consult the code of VS Code | [DeepWiki](https://deepwiki.com/microsoft/vscode) |
| Consult the code of VS Code offline | [Local DeepWiki export](#local-deepwiki-export) |
| Change the application | [VS Code fork](#vs-code-fork) |
