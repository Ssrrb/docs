# Roadmap

*Execution · draft*

## Purpose

This roadmap groups planned work into themes and initiatives. It gives an overview of work across the project.

The roadmap reflects current understanding. Feedback and new information can change, add, or defer initiatives.

## Status

| Status | Meaning |
|---|---|
| Candidate | The work needs more definition. |
| Exploring | The team is learning about the problem and possible solutions. |
| Planned | The team has selected the work, but has not started it. |
| In progress | The team is working on the initiative. |
| Done | The team has completed the initiative. |
| Deferred | The team has moved the initiative out of the current focus. |

## GitHub coordination

GitHub issues hold the detail and discussion for each initiative. A GitHub Project groups the issues and tracks status, ownership, dependencies, and work across contributors, agents, or teams.

This roadmap gives the overview. Each initiative links to its GitHub issue so contributors can find the current work.
