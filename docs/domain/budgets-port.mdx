# Presupuestos (`ecms.budgets`): anillos y puerto

*Domain · draft*

`obra-api/src/worker/budgets.ts` junta en 717 líneas la ruta, la regla, el SQL y el motor de cálculo. Esta página separa cada parte por anillo y lista lo que un módulo nuevo repetiría. `GET …/changes` ya está extraído como prueba: ruta → caso de uso → puerto, sin cambio de comportamiento.

## Respuestas

1. **Funcionalidad.** Son las rutas de la tabla. Lo que no está en la tabla no existe.
2. **Límites.** El motor (`obra-budget-engine`) aplica comandos, recalcula, importa y totaliza. El módulo pone la empresa, el idempotente, la revisión, el borrado lógico y la persistencia.
3. **Flujo de datos.** El webview habla con el host (mensajes `v: 1`), y el host con el Worker por HTTP. El token queda en el host. La base es la dueña del presupuesto: el editor pide `/changes` cada 15 s y el disco solo recibe exportaciones. No hay nada que reconciliar.
4. **Interfaz.** Está en `obra-api/src/budgets/`: `ports.ts` (`PresupuestosRepos` y `BudgetPort`), `casosDeUso.ts` (`listarCambios`) y dos adaptadores, `memory.ts` y `postgres.ts`.

| Ruta (`…/projects/:id/budgets/:kind` o `…/budgets/:id` si es suelto) | Respuestas |
|---|---|
| `GET` · `POST` crear · `DELETE` | 200 · 201/200 · 404 · 422 |
| `POST /commands`: un lote contra `baseRevision`, idempotente por `mutationId` | 200 · 409 · 422 |
| `GET /changes?after&limit` | 200 · 404 · 422 |
| `POST /restore` · `POST /import` · `POST /promote` (solo suelto) | 200 · 201 · 409 · 422 |
| `GET` · `POST /v1/organizations/:org/budgets`: índice y suelto nuevo | 200 · 201 · 409 · 422 |

## `BudgetPort`

Caja chica lo usa para comprometer un ítem del presupuesto. Está definido, sin implementar: obra-api todavía no tiene tabla de movimientos.

```ts
interface BudgetPort {
	item(projectId: string, itemId: string): Promise<BudgetItemRef | null>; // itemId = CostItem.id
	post(movement: BudgetMovement): Promise<{ id: string }>; // committed al cargar · actual al aprobar
	reverse(source: MovementSource): Promise<void>; // rechazo: anula los del comprobante
}
```

Los montos son `DecimalString`, no `number`.
