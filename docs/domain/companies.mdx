# Construction company

*Domain · draft*

## Purpose

A construction company executes an `obra`. A construction company owns projects. A construction company owns user accounts.

The name `construction company` names an entity of the domain. The company holds no rule about money. A project holds the rules about money.

## Rules

### L1-01 — One company per project

A project must belong to exactly one construction company.

### L1-02 — One company per obra

An `obra` must belong to exactly one construction company.

### L1-03 — One company per user account

A user account must belong to exactly one construction company.

### L1-04 — Several accounts

A construction company must hold one user account or more.

## Notes

The application serves one construction company in the MVP. The documents `docs/product/mvp.mdx` and `docs/execution/roadmap.mdx` state that scope.

Every account of a company holds the same capabilities. The document `docs/system/permissions.mdx` holds that rule.
