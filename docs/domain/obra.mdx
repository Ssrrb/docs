# Obra

*Domain · draft*

## Purpose

An `obra` (work site) is the unit of work of a construction company. A project groups `obra`. The name `Obras` names a module of the application. The name `obra` names an entity of the domain.

An `obra` holds the tree of work units. An `obra` holds no money. A project declares the currency of every amount.

## Rules

### L1-05 — One unit of work

An `obra` must name one unit of work.

### L1-06 — Name of an obra

An `obra` must declare one name.

### L1-07 — One project per obra

An `obra` must belong to exactly one project.

## Notes

A project can hold several `obra`. A project holds one `obra` in the MVP. The document `docs/product/mvp.mdx` states that scope.

The work unit tree is the structure of the `obra`. The document `docs/domain/work-units.mdx` holds that tree.
