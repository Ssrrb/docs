## Evidencia anterior: otro workspace desde Ctrl+

En la ronda anterior, el autor prioriza ejecutar el CLI desde la terminal integrada de Ctrl+. La entrega actual agrega npm según el contrato de distribución descrito abajo.

La selección de organización y los datos del workspace y de la obra siguen perteneciendo al asistente.

La prueba local utiliza el bundle indicado en `.research/stage2/manual-e2e.env`.
La instalación externa del tarball ya verificada conserva su valor como prueba del artefacto interno.

El entorno QA proporciona explícitamente el helper y la API productiva.
La ronda anterior excluye la publicación npm. El contrato actual sustituye esa decisión y requiere artefactos verificados antes de publicar.
Ejecutar desde Ctrl+ no restringe por sí mismo el acceso HTTP a la API.
