## Anchors

### Open Calc Studio

[Open Calc Studio](https://github.com/OpenAEC-Foundation/open-calc-studio) is the calculation engine of the application. It calculates a budget. It holds a Dutch domain model. The application embeds it and does not change it.

The document `docs/decisions/motor-integration.mdx` holds the decision and the reason.

### VS Code fork

The application is a fork of Visual Studio Code. The fork is the base of the application. The application adds the two engines as modules.

### Legacy prototype

The repository `SISTEMA-DE-CONTROL-OBRAS` is an earlier prototype. It was built to learn the problem. Its concepts and its module logic are useful. Its data model is wrong and the application reuses none of it.

### Figma

Figma designs the interface of a function.

### Sentry

Sentry will hold error telemetry. The application has no integration yet.

### docs.page

[docs.page](https://docs.page) publishes this wiki.

### Local DeepWiki export

The export of DeepWiki for Visual Studio Code sits in the folder `deepwiki-vscode-export`. It answers a question about the code of VS Code without a network service.

### Designing Data-Intensive Applications

*Designing Data-Intensive Applications* by Martin Kleppmann teaches application architecture and data systems.
