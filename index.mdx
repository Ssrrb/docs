## 💡 Key Concepts Quick Reference

### The Two Engines

| | **ERP** | **ECMS** |
|---|---|---|
| **Purpose** | Dinero y documentos | Obra y costos |
| **Asks** | ¿De dónde sale el dinero? | ¿Cuánto ejecutamos? ¿Costó qué? |
| **Owns** | Payments, invoices, contracts, accounts | Budgets, ACU, partes, certifications |
| **Decides** | What to pay, when | What to execute, how much should cost |

### The Golden Rule

```
┌─────────────────────────────────────────┐
│  ECMS measures                          │
│      ↓                                   │
│  ERP records what ECMS measured         │
│      ↓                                   │
│  Finance completes the transaction      │
└─────────────────────────────────────────┘
```

### The 4 Integration Flows

```
1. Budget → PO
   ECMS: "We need 300 kg of cement"
   ERP: "Ordering from supplier X at $0.30/kg"

2. Direct Purchase
   ERP: "Buying 50 bags of glue for $500"
   Budget: Updated automatically

3. Measurement → Invoice
   ECMS: "100 m³ of concrete completed"
   ERP: "Invoicing client 100 m³ × $400 + IVA"

4. Subcontractor → Payment
   ECMS: "Excavator completed 380 m³"
   ERP: "Paying $7,220 neto (after retentions of $380)"
```

### The 28 Modules

**ERP (8 modules)**:
Compras, Catalogs, Órdenes, Facturas, Pagos, Tesorería, Caja chica, Dashboard, Contabilidad

**ECMS (11 modules)**:
Presupuesto, ACU, Solicitudes de Materiales, Centro de costos, Partes de máquina, Precios MO, Certificaciones, Subcontratos, Stock, RRHH

**Transversales (9 modules)**:
Auth, Uploads, Reports, etc.

## 🚀 Quick Examples

### Example 1: "How does a payment to a subcontractor happen?"

```
1. ECMS: Engineer measures on site that subcontractor did 380 m³ excavation
2. ECMS: Supervisor validates and creates certificate
3. ECMS: System calculates: 380 m³ × $20/m³ = $7,600
4. ECMS: Applies retentions: -$380 (guarantee) = $7,220 net
5. ERP: Reads certificate, creates Payment record
6. Finance: Approves payment
7. Finance: Issues check/transfer for $7,220
8. Accounting: Registers egresos and retentions held
→ Result: Subcontractor paid, guarantee retained, audited
```

### Example 2: "How is real cost calculated?"

```
Presupuesto Item 5: 100 m³ hormigón @ $400/m³ = $40,000 budget

Vía A (Materiales): 
  95 m³ consumió 28.5 toneladas de árido @ $15/ton = $427,500... wait

Actually, let me redo this correctly:
  95 m³ consumió 28.5 ton árido @ $15/ton = $427.50
  + 95 m³ consumió 47.5 ton cemento @ $0.30/kg = $14,250
  = Total Vía A = $14,677.50

Vía B (Labor):
  95 m³ requirió 380 horas trabajadas
  @ $25/h + 50% overhead = $37.50/h
  = 380 × $37.50 = $14,250

Vía C (Equipment):
  Hormigonera: 4 h @ $100/h = $400
  Vibrador: 20 h @ $10/h = $200
  = Total Vía C = $600

Real Cost Total = $14,677.50 + $14,250 + $600 = $29,527.50
Presupuesto Cost = 95 m³ × $400 = $38,000
Ganancia = $38,000 - $29,527.50 = $8,472.50 ✓ Good!
```
